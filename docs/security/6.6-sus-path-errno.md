# SUSFS 2.3 / Linux 6.6 security regression audit

## Known issue: SUS_PATH errno disclosure

Reference: https://github.com/cctv18/susfs4oki/issues/1 (opened 2026-05-28, closed 2026-05-29).
Original author resolution: https://gitlab.com/simonpunk/susfs4ksu/-/commit/4f12b29ee8e7a6cb9de1fd550a350b3e4496e301.

Reported behavior in affected builds:
- A hidden parent returns `ENOENT` to a non-root process.
- Child lookups under an inaccessible hidden directory return `EACCES`.
- This errno discrepancy discloses that a hidden parent exists.

The existing `gki-android15-6.6` patch already checks `susfs_is_inode_sus_path()`
**before** `may_lookup()` inside `link_path_walk()`. This audit adds a source-level
regression guard, **not an unverified duplicate fix**.

## Mandatory on-device release matrix (not yet run)

Run from an ordinary, unprivileged Android app UID, not `su`:
1. `stat()` and `faccessat(F_OK)` on hidden parent, existing child, missing child.
2. Compare non-hidden `0700` parent with the same cases as a control.
3. Resolve via `openat()`, symlinks, paths containing `..` and long paths.
4. Compare LOOKUP_RCU/ref-walk, mount namespaces, bind mounts, and isolated services.
5. Repeat under SELinux enforcing; verify no unexpected access weakening.
6. Profile lookup latency, CPU, allocations and power against an unmodified baseline.

No assertion of full side-channel resistance can be made from a syntactic check. Timing,
statx/statfs, procfs/mountinfo, inotify and other observable interfaces require separate
threat modeling, reproducers, and test coverage. Avoid global error rewrites that violate
POSIX expectations or leak paths through alternate APIs.

## Development rules

- Changes on a dedicated feature branch; no automatic merge into production kernel.
- Preserve `CONFIG_KSU_SUSFS_SUS_PATH` compile gating and existing non-hidden lookup behavior.
- Run `python3 tests/check_sus_path_errno.py` and GitHub CI.
- Add actual kernel-level regression test and matched OnePlus 13 firmware before release.
- When the issue is demonstrably fixed and tests exist, disclose the finding/upstream patch
  without promising invisibility to all integrity or root detectors.
